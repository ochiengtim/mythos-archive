#  Mythos Archive

**Mythos Archive** is a multi-page mystical web application that simulates a digital codex of forgotten realms, relics, and arcane wisdom. Built with HTML5, CSS3, and JavaScript, it demonstrates responsive web design, JavaScript interactivity, and modern UI aesthetics.

##  Features

-  Responsive, mobile-friendly layout
-  Semantic HTML5 structure
-  Custom fonts and dark-mystic theme
-  JavaScript-powered image slider
-  Contact form with real-time validation
-  Organized file system for maintainability

##  Technologies Used

- **HTML5** – semantic markup
- **CSS3** – responsive layout, dark UI, animations
- **JavaScript (Vanilla)** – slider, form validation
- **Google Fonts** – UnifrakturCook, Cinzel, Orbitron
- **VS Code** – development environment
